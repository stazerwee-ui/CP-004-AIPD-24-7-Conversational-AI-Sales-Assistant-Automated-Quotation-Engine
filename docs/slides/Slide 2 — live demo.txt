slide 3 — Requirements

Opening:

"So what does it actually take to run this? Not much, on either side."

Hardware (gesture left):

"Hardware — any touch-enabled client device. Right now we've tested it on PC and laptop, signing with a mouse or trackpad. iPad and smartphone are next on our list

Software (gesture right):

"Software — four native web technologies, all built into the browser."

""HTML5 Canvas gives us the drawing surface, so we can draw the strokes live as the client signs.". JavaScript handles the mouse and touch events and does the Base64 encoding — that's writing the image as plain text, so it can sit directly inside the document instead of being saved as a file. CSS media print strips out the app interface so only the document prints. And the browser runs everything locally and turns it into a PDF."

The line to land on:

"The thing we'd point out here — no external libraries, no paid e-signature service, nothing hosted in the cloud. Everything runs on the machine in front of you. That was a deliberate choice, and it matches our project constraint of keeping it local and simple."
